# Production guide sources

`asset.md` is an original Local Studio planning prompt informed by img2threejs's
published staged reconstruction workflow, component hierarchy, pivots/sockets,
reference uncertainty and evidence-based review principles:
https://github.com/img2threejs/img2threejs

Inspected on 2026-09-26: installed SKILL.md and upstream README. The installed
package is Apache-2.0. No executable package code is copied or run by this guide.
This is a text-only planning adaptation, not the img2threejs reconstruction engine,
its spec format, its pass gates or a visual verification service. Generated briefs
must be reviewed before building an asset.

Director can save a reviewed asset-guide reply directly into its character, prop
or set library. The saved record is a normal editable asset brief, participates
in project Undo and project backups, and can feed the existing Build image / Build
3D actions. Saving a brief does not mark construction or review as complete.
